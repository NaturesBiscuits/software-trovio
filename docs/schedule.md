# Trovio 15-Week Schedule

This schedule keeps the project realistic for a 15-week course build. Week 2 output includes the backlog, Sprint 1 plan, schedule, and roles.

| Week | Goals | Deliverables |
| --- | --- | --- |
| 1 | Confirm project idea, target users, and core space-sharing problem. | Project concept and feature scope notes. |
| 2 | Build planning artifacts and choose Sprint 1 stories. | `docs/backlog.md`, `docs/sprint-1-plan.md`, `docs/schedule.md`, `docs/team-roles.md`. |
| 3 | Set up discovery data assumptions and basic listing model. | Listing fields, accepted listing rules, and sample data plan. |
| 4 | Implement Discover feed foundation. | Nearby available spaces displayed in Discover. |
| 5 | Add filters and preference onboarding. | Category/tag filters and onboarding preference selection. |
| 6 | Build space detail flow. | Detail screen with images, location, availability, and listing actions. |
| 7 | Add map or distance context. | Distance display or map markers connected to listing results. |
| 8 | Review Sprint 1 scope and stabilize discovery flow. | Tested Sprint 1 demo and defect list. |
| 9 | Begin rental request flow. | Request form draft with date/time, contact, and notes. |
| 10 | Add owner listing creation flow. | Listing submission form with validation. |
| 11 | Add owner listing management. | Edit availability, pricing, images, and listing status. |
| 12 | Add admin review flow. | Approve/reject workflow for submitted listings. |
| 13 | Improve recommendation signals. | Behavior event tracking and scoring refinement plan. |
| 14 | Polish UI, QA main flows, and fix priority defects. | Release candidate with test notes. |
| 15 | Prepare final demo and documentation. | Final presentation build, updated docs, and project summary. |
